# 出海研习社 · AI 海外获客训练营

面向大学生的制造业 B2B 海外获客学习平台。React 19 + TypeScript + Vite + 自定义响应式 CSS，使用 Lucide 图标，无付费后端、无需 API 密钥。

## 稳定公网发布

稳定分享地址：

- Cloudflare Pages：<https://b2b-learning-lab-0916.pages.dev/>
- GitHub Pages 镜像：<https://sisyphus070918-jpg.github.io/b2b-learning-lab/>

两个地址展示同一套学习内容。部分网络无法访问 `pages.dev` 时，可以改用 GitHub Pages 镜像。

双击 `deploy-public.cmd` 可重新发布最新内容。首次使用需要完成一次 Cloudflare 登录，此后脚本会自动构建并更新同一个公网地址。正式发布使用 `dist/` 静态文件，不依赖本机保持开机，也不经过 `chatgpt.site`。

## 启动

本机已经安装依赖。双击桌面的 `打开出海研习社.cmd`，或进入本文件所在文件夹双击 `start.cmd`；启动器会检查本地服务、在需要时启动它，并自动打开 http://127.0.0.1:5173/ 。若云端 `chatgpt.site` 地址被所在网络的 Cloudflare 安全策略拦截，可使用这个本地入口，不影响课程、搜索和浏览器学习记录。

命令行启动：

```powershell
npm ci
npm run dev
```

需要 Node.js 20.19+ 或 22+。首次在其他电脑安装依赖需要联网；安装后本地学习无须联网。不要直接双击 index.html。

生产构建与本地预览：

```powershell
npm run build
npm run preview
```

生产预览地址为 http://127.0.0.1:4173/ ，可将 `dist/` 部署到静态网站服务。

## 已实现

- 学习总览：今日任务、连续学习、完成天数、企业分析数量与技能进度。
- 八阶段学习路径：行业认知 → ICP → 潜客判断 → 外贸基础 → 商务英语 → 销售 → 客户开发 → 项目交付。每阶段包含 3 个导读、4 个深入单元、学习成果、操作步骤、作业模板、常见误区和可保存练习。
- 外部学习渠道：收录并标注中国大学 MOOC、ITC SME Trade Academy、ITC Market Analysis Tools、UN Comtrade、Trade.gov、HubSpot Academy、Salesforce Trailhead 和 WTO e-Learning，说明适合学什么以及怎样配合 28 天计划。
- Day 1 完整示例：刹车片采购链、8 个产品认知问题、10 个外贸词、ICP 输入、A/B/C 判断与 5 家模拟企业作业。
- 每日任务：Day 1–28 均有独立主题、目标、知识点、练习与交付物，可用日期选择器自由切换。每一日的 5 项任务、完成状态和复盘分别保存。
- 案例训练：5 份虚构档案，包含匹配、待核实和不匹配样本。填写角色、分级、职位、理由及策略；客观项逐项评分，误判保留并支持重做。
- 知识库：六类内容、搜索、分类和详情阅读。
- 学习进度：八项技能、等级、14 天活动、错题及 JSON 导出。
- 模拟接单：工业泵进入墨西哥等 3 个预设项目，各自保存六步方案，完整性校验、提交和 Markdown 导出。

## 数据和学习口径

课程与模拟数据在 `src/data.ts`；用户记录保存在浏览器 localStorage，键为 `b2b-learning-lab-v1`。没有向服务器发送学习记录，不跨设备或浏览器同步。不同端口、域名和浏览器使用独立记录。清除站点数据会删除记录，可在“学习进度”导出 JSON 留存；当前未实现导入恢复。原版本 Day 1 的任务记录会自动迁移到新的 Day 1 进度中。

连续学习统计当天或昨天起向前连续的活跃日期；完成学习天数需要当天 5 个任务全部勾选。企业数按不同已提交案例计数，重做不累加。阶段练习至少填写 30 个字符后可自评完成；它是学习记录，不是能力认证。能力等级按已完成阶段数为 0、1–3、4–7、8 分为四级。

案例三个客观项按教学参考评分；开放理由与策略只检查填写长度，提供参考答案供自评，没有调用 AI 评分。市场内容为教学示例与待验证清单，不是实时市场数据库。实际开发应核实企业、认证、联系方式和采购意向。

模拟方案每步至少 20 个字符，客户清单至少 5 个非空行。仅检查结构完整性，提交不等于真实客户验收，也不会联系任何企业。

支持浏览器可选 WebMCP 接口时，注册只读进度查询和模块导航工具；普通浏览器不支持时不影响功能。
